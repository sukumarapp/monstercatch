# Monster Jail Sound Effects

Put the sound effect files here:

```text
monster-catch.wav
jail-drop.wav
```

The game already plays:

- `sound-effects/monster-catch.wav` when the player catches a monster.
- `sound-effects/jail-drop.wav` when the monster is put into jail.

Prompt for `monster-catch.wav`:

```text
Create a short cute cartoon sound effect for catching a friendly little monster in a children's game. A playful boing-pop sparkle sound, soft and happy, not scary, 0.5 seconds.
```

Prompt for `jail-drop.wav`:

```text
Create a short cute cartoon sound effect for placing a silly monster safely into a toy jail. A gentle clink, happy sparkle, and soft success chime, child-friendly, not harsh, 0.8 seconds.
```
